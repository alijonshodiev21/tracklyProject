# Trackly 🚍
**Your ride, right on time.**

Trackly is a public transportation app designed to help New Yorkers and tourists navigate NYC transit. Users can search bus routes, view bus locations on an interactive map, and share transit problems with other riders.

## Features
- **Bus Tracking:** Search bus routes, choose a direction, and view bus locations using MTA data.
- **Interactive Map:** Explore NYC using Leaflet.
- **Location Services:** View your current location on the map.
- **Rider Community:** Share delays and transit problems with other riders.
- **Simple Interface:** Access transit information and community updates in one place.

## Technologies Used
- HTML, CSS, and JavaScript
- Leaflet for interactive maps
- MTA Bus Time API for bus location data
- Firebase for community chat
- Node.js and Express for the backend

## Inspiration
The idea for Trackly came from experiencing a long train delay while traveling to Manhattan. Riders continued entering the station without knowing what was happening, and official updates were not arriving quickly enough. This inspired me to build an app where riders could access transit information and share updates with each other.

## Future Improvements
- Improve trip planning to help users find routes to their destinations.
- Add report verification to make community updates more reliable.
- Bring more commuting tools into one convenient platform.

## Running Trackly Locally
1. Clone or download this repository.
2. Install the required dependencies using `npm install`.
3. Start the server using the command configured in `package.json`.
4. Open the local address shown by the server in your browser.

Some features may require API configuration or Firebase setup.
